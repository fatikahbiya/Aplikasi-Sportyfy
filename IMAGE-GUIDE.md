# Panduan foto

Timpa file dengan **nama yang sama** (huruf kecil semua, `.jpg`). Daftar path ada di `js/images.js`.
Placeholder sudah diisi tulisan path-nya, jadi kamu tahu foto mana tampil di mana.

|---|---|---|
| `assets/images/onboarding/cover.jpg` | 1000x1300 | Onboarding slide 1 |
| `assets/images/home/hero-skate-day.jpg` | 1000x1250 | Beranda: kartu besar pertama, onboarding slide 2 |
| `assets/images/sports/skateboard.jpg` | 1000x1250 | Kartu olahraga, Explore, Detail, Booking |
| `assets/images/sports/badminton.jpg` | 1000x1250 | idem |

Tips: kompres foto (maks ~300 KB per file) supaya cepat dibuka di HP.
Kalau foto tidak ditemukan, aplikasi menampilkan ilustrasi gradasi sebagai cadangan.
